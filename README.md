# درصد سود بورس

یک ابزار وب فارسی برای **مدیریت خریدهای چند نماد بورسی و محاسبهٔ سود و زیان**.

این برنامه برای جایگزینی یک فایل صفحه‌گستردهٔ محاسباتی طراحی شده است تا ثبت خریدها، پیگیری ارزش سرمایه و مشاهدهٔ سود و زیان هر نماد در یک محیط ساده و فارسی انجام شود.

## امکانات

### مدیریت نمادها

* مدیریت هم‌زمان چند نماد
* انتخاب نماد از نوار کناری
* مرتب‌سازی نمادها با **کشیدن و رها کردن**
* حفظ ترتیب نمادها پس از باز کردن دوبارهٔ سایت
* تغییر نام نماد بدون از دست رفتن خریدها و تنظیمات آن
* حذف نماد با تأیید کاربر

### مدیریت خریدها

* ثبت خرید جدید برای هر نماد
* انتخاب تاریخ با **تقویم جلالی**
* ثبت تعداد سهم، قیمت خرید و کارمزد
* نمایش جداکنندهٔ هزارگان فارسی (`٬`) در اعداد
* محاسبهٔ خودکار مبلغ خرید
* محاسبهٔ مدت نگهداری بر اساس تاریخ جلالی
* حذف خرید با تأیید و نمایش دقیق موردی که قرار است حذف شود

### قیمت پایانی و کارمزد فروش

* ثبت **قیمت پایانی** برای هر نماد
* ذخیره و ویرایش **کارمزد فروش به‌صورت مستقل برای هر نماد**
* محاسبهٔ سود و زیان هر خرید بر اساس قیمت پایانی همان نماد
* نمایش سود و زیان مثبت و منفی با رنگ‌های متفاوت

### نمودار سود و زیان

* نمایش روند سود و زیان خریدهای نماد فعال به‌صورت نمودار میله‌ای
* نمایش اطلاعات هر خرید در یک پنجرهٔ کوچک و با فونتی خوانا
* نمایش هم‌زمان:

  * نام نماد
  * تاریخ خرید
  * مبلغ واقعی سود/زیان به ریال
  * درصد سود/زیان
* نمایش مقادیر مثبت با رنگ سبز و مقادیر منفی با رنگ قرمز
* طراحی منطق نمودار به‌صورت جدا از محاسبات، برای امکان تغییر نوع نمودار در آینده

### پشتیبان‌گیری و بازیابی

* پشتیبان‌گیری از اطلاعات با فرمت **JSON** یا **CSV**
* بازیابی اطلاعات از JSON یا CSV
* تأیید پیش از پاک کردن همهٔ داده‌ها

### رابط کاربری

* رابط کاربری کاملاً فارسی و راست‌به‌چپ
* استفاده از اعداد فارسی
* استفاده از فونت **وزیرمتن**
* نمایش اعداد داخل فیلدها به‌صورت وسط‌چین
* نمایش وضعیت مناسب در صورت نبود داده برای نمایش
* حفظ وضعیت رابط کاربری، از جمله نماد فعال و تنظیمات مربوط به نمودار

## محاسبهٔ سود و زیان

مبلغ خرید هر ردیف از مجموع ارزش سهام خریداری‌شده و کارمزد خرید به دست می‌آید.

سود یا زیان نیز با توجه به **قیمت پایانی نماد و کارمزد فروش همان نماد** محاسبه می‌شود؛ بنابراین تغییر کارمزد فروش یک نماد، تأثیری بر محاسبات سایر نمادها ندارد.

## فناوری

این پروژه یک برنامهٔ وب سمت کاربر است و برای اجرای آن به سرور اختصاصی یا پایگاه داده نیاز نیست.

فناوری‌های اصلی:

* HTML
* CSS
* JavaScript
* تقویم جلالی
*  ذخیره‌سازی محلی برای نگهداری اطلاعات در مرورگر
