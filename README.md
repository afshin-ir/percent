# دفتر سهام — نسخهٔ وب

این پروژه نسخهٔ تحت‌وب صفحه‌گستردهٔ «سهام» است و برای انتشار با GitHub Pages طراحی شده است.

## ویژگی‌ها
- ورود خریدهای متعدد
- تاریخ شمسی و تبدیل خودکار به میلادی
- محاسبهٔ مبلغ خرید
- محاسبهٔ مدت نگهداری
- محاسبهٔ درصد سود هر خرید
- محاسبهٔ کل سود
- کارمزد فروش قابل تنظیم؛ مقدار پیش‌فرض همان فایل اصلی یعنی ۰٫۱۲٪ است
- ذخیرهٔ خودکار اطلاعات در `localStorage` مرورگر
- خروجی CSV
- رابط راست‌به‌چپ و مناسب موبایل

## انتشار در GitHub Pages
1. یک repository جدید در GitHub بسازید.
2. سه فایل `index.html`، `style.css` و `app.js` را در ریشهٔ repository قرار دهید.
3. در Settings → Pages، بخش Source را روی `Deploy from a branch` و branch را روی `main` و folder را روی `/ (root)` بگذارید.
4. چند لحظه بعد سایت با نشانی GitHub Pages شما در دسترس خواهد بود.

این نسخه هیچ سرور یا پایگاه‌داده‌ای ندارد؛ اطلاعات در مرورگر همان دستگاه ذخیره می‌شود.
