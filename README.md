# درصد سود بورس

نسخهٔ وب برای مدیریت خریدهای چند نماد و محاسبهٔ سود و زیان.

## امکانات
- مدیریت چند نماد در نوار کناری
- قیمت پایانی و کارمزد فروش برای هر نماد
- انتخاب تاریخ جلالی با تقویم
- مرتب‌سازی خریدها از جدید به قدیم
- نمایش رنگی سود و زیان
- نمودار سود و زیان خریدها
- ورود و خروجی JSON و CSV
- اعداد فارسی و فونت Vazirmatn
